# 바로견적 (QuickQuote) MVP

> **현장직·시공·기술자 전용 1초 모바일 견적 & 수금 비서 웹앱**  
> 모바일 브라우저에 최적화된 PWA 형태의 최소 기능 제품(MVP)입니다.

---

## 🚀 주요 기능

1. **현장 맞춤 1분 견적 작성**
   - 자주 쓰는 시공 품목 터치 한 번으로 견적서에 자동 추가
   - 수량 (+/-) 조절, 현장 할인(절사) 및 부가세(VAT 10%) 실시간 자동 계산
2. **모바일 최적화 PDF 견적서 & 카톡 공유**
   - 시공자/고객 정보가 깔끔하게 정리된 표준 A4 규격 PDF 즉시 다운로드
   - 카카오톡으로 바로 붙여넣을 수 있는 정돈된 텍스트 원클릭 복사
3. **현장 수금 & 미수금 대시보드**
   - "이번 달 총 매출" 및 "받을 미수금" 실시간 집계
   - 현장별 상태 관리 (`시공예정/미수` ↔ `입금완료`)
4. **업종별 단가표 프리셋 관리**
   - 에어컨/가전 청소, 인테리어/시공, 배관/설비, 도배/장판 기본 템플릿 지원
   - 내 시공 단가 자유롭게 추가 및 수정 (로컬 저장소 자동 보존)
5. **내 시공업체 프로필 설정**
   - 상호명, 대표자명, 연락처, 사업자번호, 입금 계좌 설정

## 💻 실행 방법

### 방법 1. 브라우저로 바로 열기
* [index.html](file:///C:/Users/kwonf/.gemini/antigravity/scratch/quick-quote/index.html) 파일을 Chrome 또는 Edge 브라우저로 더블 클릭하여 바로 실행합니다.

### 방법 2. 로컬 웹 서버 실행 (Python)
터미널에서 아래 명령어를 실행하면 `http://localhost:3000`으로 접속하여 테스트할 수 있습니다.
```bash
python -m http.server 3000 --directory "C:\Users\kwonf\.gemini\antigravity\scratch\quick-quote"
```

### 📱 스마트폰에서 앱처럼 테스트하는 팁
1. PC와 스마트폰이 같은 Wi-Fi에 연결되어 있다면 `http://[PC의IP주소]:3000`으로 스마트폰에서 접속
2. 모바일 브라우저(Safari 또는 Chrome) 메뉴에서 **"홈 화면에 추가"**를 누르면 스마트폰 앱 아이콘처럼 설치되어 전체 화면으로 실행됩니다.
