# 사장님비서 (BossAI) MVP

> **자영업 사장님을 위한 3초 배민/네이버 리뷰 답글 & SNS 홍보 AI 비서**  
> 모바일 브라우저 최적화 PWA (Progressive Web App)

---

## 🚀 주요 기능

1. **3초 배민/네이버 리뷰 답글 자동 생성기**
   - 손님 리뷰 붙여넣기 + 별점 1~5점 선택 시 즉시 맞춤 답글 생성
   - **4가지 사장님 말투(톤앤매너) 지원**:
     - 👵 다정다감 이모님 톤 (살갑고 따뜻한 단골 형성)
     - 👨‍🍳 정중·전문 셰프/대표 톤 (격식 있고 신뢰감 높은 톤)
     - ⚡ 유쾌한 청년사장 톤 (센스 있고 에너지 넘치는 톤)
     - 🛡️ 침착한 방어·수습 톤 (위생/배달/이물질 컴플레인 사과 전용)
   - 3가지 버전 동시 생성 (정성형, 깔끔형, 센스형) 및 원클릭 복사

2. **인스타그램 & 당근마켓 홍보글 3초 완성**
   - 신메뉴, 비 오는 날 할인, 조기마감 등 핵심 키워드 입력
   - **인스타 피드**: 감성 줄바꿈 + 인기 해시태그 15종 자동 추출
   - **당근마켓 동네생활**: 친근한 동네 이웃 말투의 로컬 홍보글 자동 생성

3. **단골 고객 재방문 유도 문자**
   - 재방문 쿠폰, 비 오는 날 파전 서비스, 생일 축하, 명절 감사인사 4대 템플릿

4. **내 매장 맞춤 프로필**
   - 상호명, 사장님 칭호, 동네 위치, 대표 메뉴 설정 시 모든 생성 문구에 자동 반영
